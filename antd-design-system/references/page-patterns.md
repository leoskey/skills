# 页面模式

依据官方固定提交52506486ea134486937043c5fb677d89bbcd07f2。路径均相对仓库根，详细索引见[source-evidence.json](source-evidence.json)。组件组合决定体验，Token应用于所选模式。

## 分析页 Analysis

来源 `src/pages/dashboard/analysis/`。可运行工程在 `assets/analysis-starter/`。

```text
ProLayout / GridContent
├─ Row(gutter24)：总销售额 | 访问量 | 支付笔数 | 运营活动效果
│  └─ ChartCard：Card标题 → 指标说明/数值 → 46px微图或趋势 → 分隔线/footer
├─ SalesCard：销售/访问Tabs + 日期快捷项/RangePicker
│  └─ Row：300px Column | 7项门店排名
├─ Row(gutter24)：热门搜索(NumberInfo/微图/Table) | 类别占比(Segmented/Pie)
└─ OfflineData：门店Tabs/转化率 + 时序图/slider
```

统计列：xs24/sm12/md12/lg12/xl6；body padding20px 24px 8px，指标30/38，趋势区46px，footer分隔线上内边距9px。Card标题和内部指标说明是两个角色，按参考保留。

趋势/排名列：xl16/8、lg12/12、md12/12、sm及xs各24；趋势padding `0 0 32px 32px`，排名 `0 32px 32px 72px`。下方两卡xl各12，其余各24。分析页直接进入数据内容，不另加列表式标题/描述/筛选层。

验收比较统计区、趋势区和下方双卡锚点，再检查数值、微图、排名、图表和表面。线上柱高随机时，比较图表形态/轴/配色，具体随机数不作为像素差门槛。

## 监控页 Monitor

来源 `src/pages/dashboard/monitor/`。GridContent以实时交易/状态为中心：主要监控或地图区、侧边指标、下方并列监控卡。保留时间语义、刷新与失败状态，让主要面积服务于监控对象。模板含D3世界六边形地图、交易点提示、预测Area、Gauge、三个品类Progress、WordCloud和Liquid。地图加载失败提供重试；倒计时/预测/脉冲属于动态采样。

## 工作台 Workplace

来源 `src/pages/dashboard/workplace/`。PageContainer header承载用户问候、头像/职责、项目和团队统计；正文主列为项目/活动，次列为快捷入口、团队和个人信息。项目网格、活动列表与快捷操作分别组织。模板复用官方项目Card.Grid、动态List、EditableLinkGroup与Radar；项目/团队入口可用，便捷导航支持本地新增。桌面主/次列16/8，精确还原保留官方手机三列Card.Grid。

## 查询列表 TableList

来源 `src/pages/table-list/index.tsx`。PageContainer → ProTable，自身组织搜索、标题/工具栏、列设置、数据、选择反馈和分页。ProColumns的valueType/valueEnum同时定义字段展示与搜索。创建在工具栏的400px ModalForm；详情用600px Drawer/ProDescriptions；更新使用640px Modal中的StepsForm：基本信息 → 配置规则属性 → 设定调度周期。

完整模板为 `assets/analysis-starter/src/pages/list/index.tsx`：默认折叠只显名称/描述，展开显示调用次数、状态、调度时间；搜索labelWidth120，桌面搜索区80px，间隔16px后进入64px工具栏与47px表头/数据行。默认20条/页，选中后显示选择摘要与FooterToolbar。

批量动作在选中后出现，危险操作说明对象；筛选、页码与总数一致。没有统计任务时保留列表的信息效率，不自动加四张指标卡。

## 基础、分步、高级表单

来源 `src/pages/form/basic-form/`、`step-form/`、`advanced-form/`。

- 基础：PageContainer(content) → borderless Card → ProForm；居中最大宽600px、marginTop8px，垂直字段，常规输入/日期宽md，长描述宽xl。完整模板包含标题、起止日期、目标描述、衡量标准（四项必填），客户/邀评人/权重（0–100%，选填），公开范围和部分公开时的同事选择。默认与参考一致，公开单选尚未选择。帮助/错误文本应按实际组件状态检查，不能只确认props存在。
- 分步：StepsForm分填写、确认、结果；确认展示输入，返回保留值，成功提供实际下一步。
- 高级：按任务分组多个Card，可含EditableProTable；长页使用适当FooterToolbar。布局承载复杂信息，不挤成单张窄卡。

验收字段宽度、标签、帮助/错误文本、提交反馈，以及校验出现后的布局稳定性。

## 基础、高级详情

来源 `src/pages/profile/basic/`、`advanced/`。

- 基础：PageContainer → Card → 退款申请Descriptions → 大Divider → 用户信息Descriptions → 大Divider → 退货商品ProTable（含Summary）→ 退货进度ProTable。桌面三列等宽；商品数量/金额右对齐，4条商品合计10件/61.5，5条进度使用Badge呈现进行中/成功。两个表格关闭search/options/pagination，使用ghost容器。模板在 `assets/analysis-starter/src/pages/profile/`。
- 高级：header放对象名/状态/操作，正文使用Steps、分组详情、Tabs/记录。关键操作与描述信息分开。

## 结果、异常、登录

结果/异常使用相应Result，展示结果、原因和返回/重试；成功与403/404/500语义不同。登录为独立窄表单，约328px，大控件40px，使用实际支持的认证方式。

## 业务适配

将业务内容映射到同类模式后调整字段、操作和指标。指定参考图时，页面骨架与主要组合是约束；替换业务文案不应顺带改变导航层级、卡片角色和内容比例。

## 全目录扩展

补齐计划以 [覆盖清单](page-coverage.json) 为当前模板快照，按 [逐页工作流](completion-workflow.md) 推进。该清单包含27个独立页面及共享搜索容器/通配回退；模板现已覆盖全部27页及共享/认证回退；每页有独立截图与证据，用户最终认可另记。新增高级/搜索/个人/认证等模式先读取清单中的官方源码及同目录子组件，按各自构图实施，不复用基础页作为通用兜底。


## 列表变体与共享搜索

标准列表先展示三项任务统计，再进入带状态/关键词筛选的任务列表；保留负责人、时间、进度、编辑/更多及新增弹层。卡片列表的页头说明/插图与创建卡承担引导，内容卡保持图标、摘要与操作行。

搜索容器统一页头搜索、文章/项目/应用Tabs。文章含分类、owner、自选与统计，支持加载更多；项目含封面、摘要、时间及AvatarList；应用含两个指标和下载/编辑/分享/更多操作。子页路由精确匹配，切换后的筛选与查询状态按业务规定维护。窄屏标签和筛选控件必须有可用宽度。

## 分步、高级表单与高级详情

分步表单使用三步StepsForm，确认页用Descriptions复述输入和支付密码演示，结果提供再转一笔/查看本地账单。返回应保留值，再转一笔重置第一步。高级表单按仓库/任务/成员三个Card组织12个主要字段、EditableProTable和FooterToolbar；检查错误摘要定位、行编辑/新增/删除与返回草稿。

高级详情以单号、紧凑操作组、两列描述、状态/金额、详情/规则Tabs开场；下方流程、用户信息、嵌套信息组、空来电记录、三个日志Tabs完整保留。当前官方详情/规则Tab仅改变选中状态，正文相同；业务项目需要规则内容时实现实际差异，不宣称本模板已有规则编辑功能。

## 结果与异常

成功Result包含项目说明和步骤；失败Result包含可定位错误和返回修改。403、404、500在Card内使用对应Result插图，不加多余页头；未知路径也进入404。返回、查看、打印、催办均有明确目标/反馈，演示中的打印只打开浏览器打印对话框。

## 个人与认证

个人中心左列是头像、资料、默认标签/新增可删除标签、团队；右列三个Tab分别复用文章、应用与项目组合。个人设置包含基本资料/头像、安全、账号绑定、通知四个视图；精确还原保留官方窄屏纵向菜单与头像/字段排列。

登录、注册、注册结果独立于ProLayout。登录品牌区、328px表单和40px控件；注册368px字段与密码强度/确认/验证码倒计时；结果保留账户信息与主次操作。新服务接入前，界面反馈须准确说明当前演示行为。

## 欢迎、管理与助手

欢迎页为标题、Cheatsheet Markdown主列和三张学习入口卡；当前采用线上6.0.1确切提交的中英文文档，保证内容层级和长度对应参考。管理页保留页头权限说明、Alert、中心标题与官方文档入口。

助手为Conversations侧栏、Bubble消息、Think与Markdown、Sender。发送、停止、重新生成、新建、切换和删除会话分别验证；精确还原保留官方窄屏固定会话侧栏；由此产生的狭窄消息区属于原站局限，不能将几何通过写成可用性通过。

## 页面模式的状态合同

查询表格分别覆盖展开搜索、新建/必填、配置三步、详情抽屉、选择摘要；标准列表覆盖新建/编辑/必填/成功/删除确认/页码与容量。卡片列表新增/操作与搜索加载更多在官方无完整处理函数时，明确列为本地扩展。三类搜索筛选与文章空结果需有同状态证据。

高级表单分别覆盖12项必填、成员编辑/新增、完整填写及提交反馈。设置分别覆盖头像、四项必填、安全/绑定反馈；AI覆盖流式、停止、完成、新建、切换、删除，本地重新生成为扩展。数据/资源失败、重试及刷新恢复分别拍摄，不用静态500页代替错误边界。

各类长列表与个人中心3个Tab需分段覆盖内容底部。手机宽表在容器内滚动；保留字段/操作可读性。默认不加入未要求的手机重排；业务改版需要另立目标并保存对照，不计为精确还原通过。详见expanded-acceptance.md。
