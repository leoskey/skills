## 颜色分层

| 层 | 当前使用方式 |
| --- | --- |
| 业务主色 | 当前后台 `#1890ff`；hover `#40a9ff`，active `#096dd9`，浅底 `#e6f7ff`，边框 `#91d5ff` |
| 独立认证 | 登录/注册/注册结果 `#1677ff`，hover `#4096ff`、active `#0958d9`；colorInfo也保持官方 `#1677ff` |

以少量seed保持antd派生关系。当前原站全局输入组件 `variant="filled"`。图表颜色独立于业务主色，不统一涂成同一种蓝。

## 排版与字体

| 角色 | 基准 |
| --- | --- |
| 品牌标题 | ProLayout原生18px |
| Card标题 | 16px，保留原生header与分隔线 |
| 正文/导航/字段 | 14px/22px |
| 统计值 | 30px/38px，保留官方数字字重 |
| 辅助 | 12px/20px |

原站通过@font-face加载AlibabaSans多个字重。模板 `src/fonts.css` 仅分发官方CDN声明，字体文件由CDN提供；离线时回退系统字体。检查实际字体加载、字重和基线，不能只凭font-family声明推断字体已生效。

引入 `antd/dist/reset.css` 或复用项目已有reset，避免裸h4/p/ul的浏览器默认margin破坏组件组合；已有项目避免重复reset。

## 布局与表面

ProLayout使用mix、Fluid、浅色导航、56px顶栏、256px侧栏、fixedHeader=false、fixSiderbar=true。菜单行高40px，选中叶节点为灰底深字，当前父菜单可使用主色；层级、缩进和折叠沿用组件行为。

分析页1280×720实测内容起点 `(296,88)`，即侧栏外40px水平留白、顶栏下32px留白；模块gutter24px。这是特定模式与视口的基准，不把所有页面外边距固定为24px。优先保留ProLayout内置响应式。

默认控件32px/圆角6px，小号24px/4px，大号40px；卡片8px圆角。分析页borderless卡片有细微阴影，实测为：

```css
0 1px 2px 0 rgba(0,0,0,.03),
0 1px 6px -1px rgba(0,0,0,.02),
0 2px 4px 0 rgba(0,0,0,.02)
```

容器边框、卡片阴影与浮层阴影分别处理。以参考页面和组件类型决定表面效果。

## 状态与文案

操作名体现对象与结果，字段有可见label，错误与字段关联。提交防重复、失败保留输入。ProTable组织搜索/工具栏/列设置/选择反馈/分页，保持筛选状态与数据一致。图表有标题、单位、tooltip；日期和渠道变化应改变相应数据。加载、空数据、失败分别呈现。

演示数据可固定以便回归，交付时说明服务边界。图标按钮有可访问名称，保留焦点和减少动效偏好。原站颜色不自动证明所有状态满足WCAG AA；有要求时检查实际组合并说明必要调整。
