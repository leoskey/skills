# 基础与布局

## 两种密度

| 用途 | 排版起点 | 布局与分组 |
| --- | --- | --- |
| 产品工作区 | 正文 13–14px，元数据 11–12px，详情标题 20–24px | 紧凑导航、明确分栏、独立滚动、较少容器 |
| 展示网站 | 正文 16–18px，标题根据视口从约 36px 扩展至 80px | 有限行长、清晰章节、真实功能叙事、产品视觉展示 |

上述尺寸不是硬性标准。中文、复杂数据、触控、放大和目标人群可能需要更大的字号或行高。不要把官网的大标题、宽章节间距直接放进生产力工作区。

## 表面与颜色

[tokens.json](../assets/tokens.json) 区分 `product` 和 `marketing` 两个参考配置。Web 样式仅定义在 `.linear-theme` 范围内，并以 CSS 变量提供；不会修改全局 body。

产品参考：画布 `#101112`，侧栏 `#131415`，工作面 `#191a1b`，抬升面 `#232425`，分隔线 `#2c2d2f`，输入边框 `#3b3c3e`。正文 `#e1e2e6`、次要文字 `#a0a3ac`、元数据 `#858993`。

蓝紫主操作背景为 `#5e6ad2`，白色文字；图标、焦点和小范围强调使用更亮的 `#727be8`。语义色应根据目标业务映射，不能机械规定“上涨为绿”。文本与控件在实际背景上单独测量对比度，细边框也不能成为唯一可见的操作提示。

官网参考使用更深画布 `#010102`、深色内容面 `#0f1011` 和更亮标题 `#f7f8f8`。这些值来自第三方参考整理，并非经过官方确认的完整设计变量。

## 字体、图标与间距

- 优先使用现有字体。Web 可使用 Inter 或系统无衬线回退；中文保留平台合适的字体回退。不要假定 Linear 的专有字体可公开取得或再分发。
- 标题通常使用 500–600 字重与轻微负字距；正文保持自然行高。标识符、表格数字根据需要使用等宽数字，避免把全部文字改为等宽。
- 从 4、8、12、16、24、32、48px 的间距起点调节。产品内分组依靠距离与对齐，少用大空卡片；网站章节允许更宽的留白。
- 图标以 14–16px 视觉尺寸起步，但外层点击目标至少 24×24px，触屏主要操作宜达到 44px。图形尺寸不等于交互面积。
- 小控件约 6px 圆角，工作面与输入容器约 8–12px；胶囊主要用于筛选或短标签，避免所有按钮都变成胶囊。

## 工作区布局

三栏适用于需要在上下文中处理记录的任务，不是所有页面的固定要求。

| 区域 | 桌面参考起点 | 约束 |
| --- | --- | --- |
| 主导航 | 约 220–250px | 分组和选中项清楚；底部内容不能覆盖导航 |
| 列表 | 约 280–350px | 标题截断，辅助信息可读；保留选中状态 |
| 详情 | 使用剩余宽度 | 长标题、正文、评论可换行；主要动作可见 |
| 可选属性区 | 约 180–240px | 内容不足时折叠，不能挤压正文形成细条 |

根工作区使用可收缩布局；Web flex 子项常需要 `min-width: 0`，滚动子项常需要 `min-height: 0`。让列表与详情分别滚动，避免顶部动作被长内容推走。

按内容实际容纳能力切换布局，而不是生搬硬套断点。中间宽度优先隐藏辅助属性或折叠导航；窄屏让列表、详情依次出现，提供返回列表的入口。切换时保留选中项、滚动位置与未提交输入。

外部展示框、底部氛围背景和设备边框不是工作区必需部分。已有应用一般保留自身页面壳层。
