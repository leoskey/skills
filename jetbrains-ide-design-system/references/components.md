# 组件与布局

| 模式 | 使用决策与要求 |
| --- | --- |
| 工作区 | 面向多资源、多任务的工具产品，外层工具栏和操作栏低强调，按任务分成岛屿，保存实际面板状态 |
| 普通业务页 | 表单、列表、详情只需应用字体、语义色、控件和密度，导航使用业务名称 |
| 工具面板 | 树适合侧栏，宽表格/日志适合下方；关联动作置于标题栏；空状态给出下一步 |
| 标签页 | 当前项有填充和轮廓；关闭按钮命名；关闭当前项后选择邻项并移动焦点 |
| 按钮 | 具体动词、每个对话框一个主操作；需要后续输入可用省略号；不可逆操作明确确认，安全操作为默认 |
| 输入与选择 | 持久标签、适当宽度、程序关联错误；只读与禁用分开；可枚举值使用选择控件 |
| 树与列表 | 真正 tree 需要方向键和展开模型；否则用原生 details/summary 加列表表达层级 |
| 菜单与弹层 | 平台控件或成熟库；检查初始焦点、Escape、外部关闭及焦点返回 |
| 设置 | 邻近字段标签对齐，窄屏改上标签；即时保存或真实 Apply/Cancel 事务二选一 |
| 反馈 | 成功/警告/错误使用语义色加文本；错误给恢复路径，加载可取消时提供取消 |

## 跨端适配

本包 760px 是起始断点。窄屏将资源栏改抽屉，主内容允许缩小；宽代码/表格只在自身区域滚动。标签条可横向滚动，工具栏动作按优先级收拢。

产品需要可调面板时使用成熟 split pane，同时提供键盘调整。示例固定初始宽度不等于实现拖拽。恢复布局须限制到当前视口有效范围。

区域失焦保留选择。Web 区分焦点在组件内与 document.hasFocus()；Flutter 使用 FocusScope 和生命周期。官方窗口 inactive overlay 未在本包移植，仅在产品确有需要时实现。

Web gallery 演示资源层级、可关闭标签、主题、设置事务、窄屏抽屉与控件状态。Flutter starter 演示主题、筛选列表、设置事务、验证和响应式侧栏。它们不包含真实 IDE 引擎、文件系统、编译或后端保存。
