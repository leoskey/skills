# 验收

包校验 `python scripts/validate.py` 检查离线来源哈希、颜色别名、生成 CSS/Dart 一致性、指定正文/按钮/状态文字对比度、文档链接和字体。它不检测实际渲染、键盘行为或所有官方颜色组合。

接入页面需检查：

- 1440px、1024px、390px 明暗主题；长文本、空内容、错误、侧栏和弹层可用，主页面无意外横向溢出。
- 默认与 200% 文字缩放，英文、中文、长路径及 CJK 回退字体实际渲染。
- Tab/Shift+Tab、Enter/Space、Escape，受影响树、菜单、标签页各自方向键模型。
- 当前项、悬停、按下、焦点、禁用、失焦选择分别成立。
- 设置 Apply、Cancel、Escape、无效输入、保存失败和恢复路径符合实际业务。
- 与官方层次、字体、间距、状态对照，记录适配差异。

交付表述区分包校验、Flutter analyze/widget 测试、浏览器验证、指定环境截图与真实设备/用户验收。本地示例状态不证明后端保存、文件写入、代码运行或外部服务。
