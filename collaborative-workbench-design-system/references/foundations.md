# 基础与主题

## 信息结构

导航回答“在哪个范围”，列表回答“有哪些工作”，详情回答“发生了什么、下一步是什么”。桌面允许同时查看三者，避免把每行变成独立卡片。元数据在列表内简写，在详情中完整呈现；长标题允许换行，关键状态不截断。

默认布局起点：导航 208px，集合区至少 320px，详情区至少 300px；间距 4/8/12/16/24/32px。宽度不足时先折叠导航为原生选择控件，再让详情成为单独视图，并保留返回列表与原焦点。断点由内容容纳能力确定，示例采用 1100px 和 720px，不是设备标准。

同一工作面主要用间距和分隔线分组；浮层才使用阴影。内容左对齐；列表标题、执行者、状态使用稳定列，数字使用等宽数字。不要用装饰图表、虚构指标或品牌 Logo 填充空白。

## 原创语义主题

`assets/tokens.json` 是唯一数值来源，CSS 为对应输出；变更需同步并运行 `scripts/validate.py`。这些值独立制定，不来自 Multica、Linear 或其他产品的 token。

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| canvas / surface | #f3f6f8 / #ffffff | #111a21 / #18242d | 画布与工作面 |
| text / muted | #182a36 / #526573 | #e9f1f5 / #afc1cc | 正文与元数据 |
| accent / onAccent | #086b61 / #ffffff | #83d9c5 / #10241f | 主要操作 |
| selected | #e2f3ee | #233f3c | 选中背景，同时有边线或语义属性 |
| border / control | #d5dfe5 / #6c7e88 | #354650 / #859ba8 | 分组线 / 必要控件边界 |

正文 15px/1.6，元数据 13px/1.5，页面标题 24px/1.3；控件至少 36px 高，触摸场景优先 44px。系统 UI 字体加中文回退，不下载未授权字体。圆角 6px 用于控件，10px 用于浮层；不要把全部区域做成卡片。

主题包括文字、表面、必要边界、选中、焦点、成功、警示、危险和禁用。初始跟随系统偏好，显式选择优先；是否持久保存按产品需要决定。深色不是简单反色。状态文字、图标和颜色共同表达含义。

改变字号、密度或品牌色后重新测试真实长内容、200% 缩放与主题对比度。token 是起点，不能替代合成背景上的实际测量。
