# 验收

运行 `python scripts/validate.py` 检查资源链接、token 与 CSS 同步、主题关键配色。另运行 skill-creator 的 quick_validate.py 检查技能格式。它们不证明完整无障碍合规。

示例浏览器回归需在独立验证环境安装 `playwright`，使用已有 Chromium / Chrome：

```sh
python scripts/verify_preview.py --browser "<浏览器可执行文件>" --output "<技能目录以外的截图目录>"
```

该脚本不安装浏览器、不访问外部站点，也不连接业务后端。基础校验仅依赖 Python 标准库。[示例验证记录](validation.md) 说明已测范围及限制。

在目标应用执行以下检查，并记录实际结果与截图：

- 1440px、900px、390px 代表视口；浅色和深色。观察截图本身，检查长标题、中文、空结果、选中状态与主要动作；200% 缩放检查重排与遮挡。
- 搜索、清除、选择记录、窄屏返回、创建必填校验、取消与成功、完成状态更新。若接后端，增加加载、失败、重试、无权限与重复提交检查。
- Tab / Shift+Tab、Enter / Space、Esc、对话框焦点约束及恢复。检查可见焦点、控件名称、表单错误关联和礼貌播报。
- 文字对比度普通文字至少 4.5:1、大字至少 3:1；必要控件和状态图形至少 3:1；使用实际背景及适用 WCAG 例外。目标至少 24×24 CSS px 或适用间距例外，触摸场景优先更大。
- 跟随系统初始主题、显式主题选择、减少动态效果、长内容与键盘可达性。没有动画也要确认不会引入无必要的运动。

最多三轮“渲染 → 检查 → 修复”。报告视口、主题、截图位置、代表性字号 / 行高 / 几何数据、实际交互结果与未检查项；避免把 DOM 检查、构建通过或少数 token 配色通过当作视觉 / 全面无障碍验收。
