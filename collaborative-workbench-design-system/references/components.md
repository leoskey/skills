# 组件契约

| 组件 | 内容与状态 | 交互契约 |
| --- | --- | --- |
| 范围导航 | 当前范围、可用范围；加载、无权限、失败 | 真导航用链接；本地筛选用按钮或 select；选中状态可由辅助技术读取 |
| 集合工具栏 | 标题、结果数、搜索、主要操作 | 搜索保留可见 label；清空搜索可恢复；结果变化礼貌播报；不要抢焦点 |
| 记录行 | 标题、状态、执行者；选中、悬停、焦点 | 使用原生按钮或链接；Enter/Space 可选择按钮；不强行标记为需箭头键管理的 ARIA listbox |
| 详情面板 | 完整标题、状态、责任人、活动与下一步 | 窄屏是有返回入口的页面；切换时聚焦标题，返回聚焦原记录；桌面选择后避免不必要地移动焦点 |
| 执行者 | 人员或自动化类型、显示名、必要的执行来源 | 类型与权限独立；头像不能代替名称；不从自动化身份推导审批权 |
| 执行状态 | 排队、执行中、待处理、成功、失败、已取消等真实后端枚举 | 明确可恢复动作；失败保留原因和已完成部分；避免只显示转圈或假进度 |
| 表单 / 对话框 | 名称、说明、错误、提交状态 | 可见 label、必填提示、错误关联；提交期间防重复；Esc 关闭、焦点约束、关闭后返回触发点 |
| 活动记录 | 动作、主体、时间、结果 | 使用真实来源；乐观更新失败时恢复并说明；长日志按需展开，不阻塞主任务 |

空集合给出创建入口，无匹配结果给出清除筛选入口；加载保留布局并设置 busy；失败提供重试且不清空已有内容。禁用动作解释原因；危险操作明确影响、对象和恢复能力，确认层级依据实际风险决定。

示例只演示“待处理 → 已完成”的本地转换。接入真实应用时从服务端映射状态、权限和动作，不能把示例转换当作执行引擎。完成后更新行、详情和结果播报，保持同一事实来源。
