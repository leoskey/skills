# 基础与布局

所有数值以 [tokens.json](../assets/tokens.json) 为来源；CSS 由该文件生成。这里说明如何选择和应用角色，避免把示例中的精确数值误当成官方约束。

## 表面与主题

| 角色 | 暗色 | 亮色 | 用途 |
| --- | --- | --- | --- |
| canvas | #101011 | #EFEFF2 | 外围工作区或辅助导航 |
| bg | #151515 | #F6F6F8 | 应用背景 |
| surface | #202123 | #FFFFFF | 常规表面与容器 |
| raised | #292A2D | #FFFFFF | 浮层、菜单、次级控件 |
| selected | #28282B | #EDEDF2 | 中性选中区域 |
| text | #F5F5F7 | #202027 | 标题与主要内容 |
| text-secondary | #BFC0C8 | #51515F | 常规辅助内容 |
| text-tertiary | #A0A1AB | #676775 | 时间、注释、提示 |
| body | #D2D2D8 | #3F3F4C | 长文本阅读 |
| brand | #FF6363 | #FF6363 | 品牌填充与主按钮背景 |
| on-brand | #151515 | #151515 | 品牌按钮文字 |
| accent-text | #FF8585 | #BE293C | 强调文字与文字链接 |
| focus | #A6C8FF | #305FDA | 键盘焦点轮廓 |

需要其他表面时补充语义角色，不在组件里随意写一组十六进制颜色。常规表面不以强阴影分隔；浮层可以使用阴影增强深度。选中、悬停、禁用和焦点分别定义，不能共用同一个“灰一点”状态。

`brand` 与 `accent-text` 的角色不同。主按钮采用 `brand / on-brand`；小字链接采用 `accent-text`。状态颜色使用 success、warning、danger、info，并配文字或图标，不用珊瑚红代替所有状态。

## 字体与阅读

使用系统无衬线字体栈：SF Pro / 苹方、Segoe UI / 微软雅黑，再回退到系统 sans-serif。代码和快捷键按需使用系统等宽字体；不打包或下载专有字体。

| 内容角色 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 页面标题 | 24px / 35px | 500 |
| 区域标题 | 20px / 28px | 500 |
| 阅读正文 | 15px / 28px | 400 |
| 普通正文、列表标题 | 14px / 22px | 400；未读或强调 500 |
| 控件标签 | 13px / 20px | 500 |
| 辅助说明 | 12px / 18px | 400 |

- 11px 只考虑用于非关键的短注记；不用于用户必须辨认的操作、摘要或状态。
- 中文正文不使用负字距；中英文混排以自然换行为主，不插入只为某个视口服务的硬换行。
- 长文本推荐约 32–44 个汉字的行宽，根据窗口和内容调整。用段落间距分组，不依赖空行字符排版。
- 先检查实际字体回退、字号与字重，再判断是否需要换字体。高像素密度预览可以避免截图缩放造成的误判，但不能替代真实浏览器阅读检查。
- 暗色界面不把所有文字都设为纯白。通过颜色和轻微字重差区分层级，不给每一行都加粗。

## 几何与密度

- 间距：4、8、12、16、20、24、32、48px。行内图标与标签通常间隔 8px，模块间距通常 24px。
- 圆角：6px 小控件、8px 常规控件与行、12px 内容面板、16px 主窗口。内外嵌套时内层半径更小。
- 桌面控件通常高 36px；紧凑列表行通常至少 44px；搜索区域通常高 56px。多行内容自然增高，不能裁掉主要信息。
- 图标通常 16–20px，描边约 1.5–2px。触屏目标按平台扩大到约 44 × 44px，图形本身不必同步放大。
- 1px 边框用于结构分隔；焦点轮廓 2px、外偏移 3px，与选中背景独立。

## 页面模式

按内容与任务选择布局，不复制营销官网的展示密度：

- 命令面板：搜索 → 分组结果 → 当前项 → 默认动作与更多操作。
- 列表与详情：列表适合扫描，详情适合阅读；是否分栏取决于窗口宽度与需要对照的内容。
- 内容网格：图片确实是识别主体时使用；保证名称和元信息可读。
- 表单与设置：标签常驻，字段按任务分组；错误紧邻字段。

侧栏、列表栏和详情栏不是固定需求。窄窗口可变为单视图逐级进入，返回时保留筛选、位置与编辑内容。品牌色与业务状态不随布局切换而改变含义。
