# Raycast Design System

一套从 Raycast 产品气质提炼的独立设计系统。核心是低干扰的表面层级、克制的珊瑚红、清晰的信息密度和键盘优先的操作。它不等同于 Raycast 官方 token、原生组件 API 或可直接发布的应用。

## 使用方式

1. 确定本次是资料查阅、界面审查还是实现。读取目标项目的组件、主题和业务结构；局部调整只修改指定范围。用户已经确认的布局、语言与品牌选择优先。
2. 阅读 [基础与布局](references/foundations.md)。以 [tokens.json](assets/tokens.json) 为实现数值来源；Web 可复用 [tokens.css](assets/tokens.css) 和 [components.css](assets/components.css)，其他平台映射到原有主题系统，不为套风格更换技术栈。
3. 按涉及的界面读取 [组件与交互](references/components.md)。命令面板、列表、详情与表单是可选内容模式，不要求每个产品都创建侧栏、三栏布局或某种业务功能。
4. 根据目标平台实际渲染，用 [验收清单](references/quality.md) 检查主题、排版、焦点、状态与任务路径。需要展示对照时打开 [概念预览](assets/preview.html)；它用于说明视觉规则，不能代替目标应用的验证。
5. 交付说明本次修改、实际运行的检查和未覆盖的限制。审查任务给出可复现的问题、影响和具体修复建议；未要求修复时不顺带改代码。

## 视觉判断

- 用中性表面和细边框建立层级。列表选中态以中性灰为主；珊瑚红用于少量关键动作和必要的品牌强调，不代表所有业务状态。
- 明暗主题分别映射背景、正文、辅助信息、边框、选中态、浮层与焦点。品牌填充色与强调文字色分开：亮色主题不能将浅珊瑚红直接用作小字颜色。
- 中文优先保障清晰度。普通正文 14–15px、阅读正文 15px、列表标题 14px、辅助说明通常 12px；正文使用 400、局部强调使用 500。不要为密度把主要信息压成 9–11px，也不要对中文正文施加负字距。
- 4px 间距基准、6/8/12/16px 圆角、36px 桌面控件与 44px 列表行是起点；字号、内容长度与目标设备决定最终尺寸。空间不足时调整换行或视图，不缩小正文去硬塞。
- 快捷键是鼠标入口的补充。选中项、键盘焦点和当前打开内容是不同状态，须分别管理；更新视图后保持可感知的位置。
- 纹理、渐变和阴影服务于层级或独立的预览内容，不给工作区叠加大面积装饰。已有图片与文档预览保留自身色彩，不随主题反色。

## 来源与边界

[来源与维护](references/sources.md) 区分三项官方品牌色和本系统的提炼值。其余颜色、字体尺寸、密度、亮色主题与交互规范均为独立实现建议；不宣称来自官方设计源文件。

资源不包含官方 Logo、专有字体、用户提供的原稿、个人账号或特定产品的业务数据。预览中的功能和示例文字只说明样式，不应自动进入目标产品需求。

调用示例：

- “使用 $raycast-design-system 设计一个桌面记录列表与详情页，保留现有业务和技术栈。”
- “使用 $raycast-design-system 为当前界面补充亮色主题，检查正文、标签、浮层与焦点。”
- “按照 $raycast-design-system 审查这个工具的搜索、编辑和键盘路径，先报告问题，不修改代码。”
