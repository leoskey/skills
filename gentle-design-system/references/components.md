# 组件契约

尺寸、颜色和阴影引用 token；下列尺寸均为建议。每个组件接受真实内容、语义状态和动作，避免把示例文案、业务字段或数据写死在组件中。

| 组件 | 结构与视觉 | 状态与行为 |
| --- | --- | --- |
| AppShell | 200px 侧栏；上部标识、搜索与主导航，下部通知、设置与账户；主内容可独立滚动 | active 项深炭色底白字；hover 轻灰底；折叠后仍保留名称提示与键盘导航 |
| PageHeader | 左侧标题及可选面包屑／副标题，右侧时间、范围、导出／主行动 | 窄屏工具条换行；标题优先于操作；面包屑当前项不是链接 |
| SurfaceCard | 20px 圆角、20px 内边距、1px 边框；标题与右侧补充说明／更多菜单 | 有动作时才出现菜单；普通卡片不整体表现成可点击按钮 |
| MetricCard | 标签、时间范围、大数字、变化 chip、解释、可选迷你图与分项 | positive/negative 依据业务意义；数字加载时骨架保留宽度；错误显示重试，不显示假零 |
| Button | 默认深炭色主按钮、浅灰次按钮、白色轻按钮；34px 高、左右 12px、10px 圆角 | hover 稍加深；focus-visible 清晰蓝环；pending 保留文案与宽度；disabled 不可触发 |
| Search / Filter | 搜索图标、输入文字、可选快捷键提示；过滤器为相邻轻按钮 | 快捷键提示仅在已实现时显示；清空按钮、输入名称、过滤后结果数；错误解释在字段附近 |
| SegmentedControl | 轻灰轨道，白色选中块和极浅阴影 | 单选语义和键盘左右切换；只切换相关视图，不意外修改业务数据 |
| StatusChip | 白色或极浅语义底、小圆点和短标签，细边框、全圆角 | Critical / At risk 等有文字；颜色不单独承担状态识别 |
| DataTable | 小号弱表头；一行主文和一行说明；每行约 46–52px；细水平分隔 | hover 浅灰；selected 细蓝轮廓且有选中语义；排序按钮暴露方向；操作与行点击不冲突 |
| Tooltip | 小型白色胶囊、浅阴影，字段间以留白或细分隔线分组 | hover 和键盘 focus 均可见；触屏提供点击方案；不可只在提示框里藏必要数据 |
| InsightCard | 一张渐变卡，顶部轻描边标签、大数字、结论、证据与底部白色按钮 | 卡片高度跟随内容；按钮连接相应记录或配置；没有证据时不要写成“已发现模式” |
| ActionList | 标题+计数；图标圆底、主句、辅助说明、右箭头；行间细分隔线 | 每行一个明确动作；无待办显示完成状态，不保留无意义空行 |
| CauseCard | 语义图标、右上损失数字、原因标题、短解释、底部文字动作 | 多列时动作对齐；不通过固定正文高度裁切翻译后的文字 |
| ScenarioCard | 图标、右上开关、标题、改善值、纹理短条、说明 | 选中态蓝色边框与语义状态同时存在；开关改变模拟结果，另用保存动作提交情景 |
| DrillPath | 浅色横条、路径 chip、箭头、当前节点暖色底、末尾重置 | 点击上层退回对应范围；路径过长允许横向滚动；重置恢复明确的默认范围 |
| ChangeModal | 桌面约 480px 宽；白底 20px 圆角；标题和关闭按钮、影响说明、旧值→新值、选项、收益说明、底部动作 | Esc 关闭、焦点圈定、关闭后恢复触发点；提交中防重复；成功／失败反馈；长内容滚动，移动端宽度减两侧 16px |

## 表格细节

文本左对齐，金额和可比较的数字右对齐；数值单位在列标题或单元格里明确。双行信息的次行不能比正文更突出。短纹理条需说明量纲和目标，不能只是装饰。行选中用边框而非大面积蓝底；Web 可使用 inset box-shadow 避免选中时尺寸跳动。导航行与复选选择应区分语义。

分页只在真实有更多内容时出现；当前页深炭色圆底。页码、结果总数和当前展示范围一致，删除或过滤后处理空页。

## 交互与数据状态

- Loading：灰白骨架保留最终布局；不要用随机假数字或假图表。减少动效设置下禁用闪烁和 shimmer。
- Empty：在原容器内说明“暂无数据”及下一步；空与数值零分开。
- Error：保留已加载内容和上下文，在相应区域显示失败及重试。
- Focus：2px 蓝色轮廓、2px 间距；不要用不可见的阴影代替键盘焦点。
- Disabled：保持可读的文案，明确原因；禁用状态无需模仿可交互的 hover。
- Motion：默认 140–180ms 的颜色／透明度过渡；图表更新尊重用户减少动效设置，不做夸张弹性动画。
