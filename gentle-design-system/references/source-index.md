# 设计来源与预览

此设计系统提炼自用户提供的六张浅色数据产品设计稿。原始 JPG 不包含在公开仓库中，也不作为可复制的产品资产。

## 重新设计的预览

[查看 PNG 预览](../assets/preview.png) · [查看可编辑 SVG](../assets/preview.svg)

预览为本仓库重新设计的工作区概念界面，使用虚构品牌、人员和示例数据。它展示灰白表面、大数字、细边框、蓝色纹理图表与局部渐变，不是原图翻拍，也不是已实现产品的运行截图。预览中的按钮是静态示意。

## 原始观察范围

| 页面类型 | 提炼内容 |
| --- | --- |
| 概况 | 壳层、KPI、趋势、差异图、洞察与待办 |
| 记录列表 | 点阵分布、目标线、筛选、双行表格、选中行与分页 |
| 变动详情 | 面包屑、桥接图、直接标注与原因卡 |
| 异常分析 | 累计指标、热力矩阵与行动建议 |
| 下钻与弹窗 | 路径、对比点图、参数调整与影响说明 |
| 预测 | 指标带、实线／虚线、区间与情景开关 |

**直接观察**：构图、颜色角色、相对层级、留白、纹理和浮层。

**估算并规范化**：HEX、字体、字号、圆角、阴影、逻辑像素尺寸；无原始 Figma 数据，不声称是精确取值。

**为复用补充**：断点、交互状态、键盘与读屏支持、减少动效和移动端规则；这些未在原设计稿中验证。
