# 页面配方与响应式

桌面布局可从约 200px 侧栏和弹性主内容区开始；以下比例比固定像素高度更重要。页面内容应随真实信息量调整，不能为了填满屏幕而添加无关图表。

| 页面 | 桌面结构 | 阅读顺序 |
| --- | --- | --- |
| 概况页 | 三列约 1:1.05:0.95，间隙 16px；左侧 KPI 与周趋势，中列跨两行差异图，右侧洞察与待办 | 现状→偏差原因→行动；DOM／语义顺序也按此组织 |
| 记录列表 | 顶部全宽点阵分布；下方列表卡含搜索、筛选和分页 | 分布→低值或优先项→记录详情 |
| 变动详情 | 面包屑+标题；全宽大型桥接图；下方四张同级原因卡 | 计划与实际→逐段变动→可执行修正 |
| 异常分析 | 顶部左 1/3 KPI、右 2/3 热力矩阵；下方一张大卡容纳三列行动 | 总量→发生位置→优先处理项 |
| 分层下钻 | 路径条；关联列或分层列表；下方 2/3 对比图+1/3 建议卡；动作打开模态框 | 范围→归因→证据→调整 |
| 趋势与情景 | 四项横向指标带；全宽趋势图；下方四张情景开关卡 | 基线→时间变化→假设→保存 |

为桥接图和预测图预留约 320–420px 图形高度；普通迷你图约 120–180px。高度只是起点，标签多时增高。表格不能为固定卡片高度而隐藏记录却保留错误总数。

## 响应式补充

这些断点是实现建议，依据主内容可用宽度及实际组件最小宽度选择。

- ≥1200px 视口：完整侧栏与三／四列内容；实际可用内容宽度不足时提前降列。
- 900–1199px：可将侧栏折成约 64px 图标栏；主卡两列；洞察卡移到下一行；四张原因卡变 2×2。
- 600–899px：侧栏变抽屉；内容 20px 内边距；能容纳的短卡两列，主要图表一列；工具条换行。
- <600px：内容 16px 内边距、单列；标题可降至 28px；横向指标带转 2×2 或单列；普通卡片 padding 16px。保持 44px 触摸目标。

宽表可用独立的横向滚动区并保留记录标识，或转换为记录卡；页面整体不横向溢出。热力矩阵／桥接图优先受控横滚或提供数值列表，不把所有轴标签挤在一起。模态框最大高度受视口约束，正文可滚动，提交动作可见；屏幕键盘不能盖住输入与主要操作。

## 跨业务迁移

按信息角色选择布局：概况、核心记录、异常分析、变化解释或趋势情景。没有对应需求的页面不创建。导航命名采用目标产品用户语言；一张卡只表达一个决策问题。状态分级阈值来自业务定义，不继承示例数据。
