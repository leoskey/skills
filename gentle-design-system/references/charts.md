# 数据可视化语言

## 共用规则

图表背景透明，融入卡片。图例为小色点／线样式 + 文本。网格非常轻，目标线为细炭色虚线并直接写明值。小数据集优先直接标注，避免依赖悬浮提示。金额、百分比和百分点区分：34% 到 38% 是 4 个百分点，不是增加 4%。

历史／剩余值使用细蓝斜线，损失使用洋红斜线，最新／最终值使用实心电蓝色。纹理建议 45°、1px 实线 + 3px 空隙；在目标显示比例检查摩尔纹。图表尺寸很小时可改为实心色并保留标签。颜色、纹理、线型及文字联合表达语义。

图表提供标题、时间范围、单位、关键结论及文本摘要／数据表。仅用 canvas 或 CustomPainter 画图时补足可访问语义；交互点可通过键盘或列表访问。目标与阈值来自业务定义，不继承演示数据。

## 图表配方

| 类型 | 实现规则 | 数据约束 |
| --- | --- | --- |
| KPI 目标条 | 蓝纹理填充，独立黑色目标刻线，下方明确当前／目标值 | 非零起点必须标注；不要将截断条长误称为占整体比例 |
| 周趋势柱 | 前期细蓝纹理柱，最后一期实心蓝；黑色虚线目标、首末日期与末值 | 柱图原则上从零开始；缺失值留空或显式标记，不补成零 |
| 差异瀑布 | 目标在上，按贡献逐项递减，细虚线连接各阶段，最终实际值实心蓝 | 起点 + 有符号变动之和 = 终点；有正贡献时方向相反；不能固定画成全部损失 |
| 指标桥接 | 阶段总量用蓝纹理柱；不利变动用洋红段、有利变动用绿色；顶部显示阶段总量与本次变动 | 前一阶段总量 + 本次有符号变动 = 当前阶段总量；使用真实数据计算；填充连接面不改变柱值 |
| 点阵直方图 | 每点一个对象；按横轴数值区间堆叠；状态颜色随阈值变化；目标竖虚线 | 点数与对象数量一致，声明 bin 宽；大数据可改聚合图并明确每点代表数量 |
| 矩阵热力图 | 行为实体、列为原因，单元格圆角约 10px；洋红浅到深；每格标值，边缘有合计 | 色阶使用一致量纲及明确阈值；空数据与零区分；深色格切白字，浅色格用深字 |
| 估计／实际点图 | 两条同轴分布，共享小时或其他单位；估计蓝、实际洋红，中心统计量标记 | 不把平均数与中位数混用；拥挤采用 beeswarm 或可解释分箱；两组轴范围相同 |
| 预测趋势 | 实际蓝实线+实心点；基线预测蓝虚线+空心点；情景预测绿虚线；未来区间淡蓝底 | 历史和预测有边界；区间须有数据来源与含义，不能编造置信度；情景非承诺 |

## 数值一致性

所有图形、悬浮值、列表和摘要来自同一数据源。金额在展示层统一舍入；总计基于原始值计算。点阵图例数等于可见对象数或清楚说明过滤范围。比例必须标明分母；预测开关组合需要真实模型或显式的演示假设，不默认将百分比机械相加。

曲线不使用会暗示未观测极值的过度平滑。趋势折线允许为阅读变化使用截断纵轴，但刻度必须清楚；用面积、柱高表达总量时保留合理零基线。图表容器太小时减少非必要刻度，不压缩关键文字到不可读。
