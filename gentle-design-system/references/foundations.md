# 基础规范

## 表面与颜色

精确值见 [tokens.json](../assets/tokens.json)。基础风格是轻微冷灰的工作区，卡片与背景色差很小；黑色文本承担主要对比。辅助文字也应保持足够对比度，使用语义文字色，不为追求轻盈而牺牲可读性。

| 语义 | 用途 |
| --- | --- |
| canvas / shell / surface / elevated | 外部展示底、工作区、卡片、菜单或弹窗 |
| text / text-secondary / text-muted | 主文、说明、辅助标签；muted 仍是可读文字，不是 disabled |
| border / control-border | 表面细分隔线／输入控件轮廓；不可用浅装饰边框代替必要控件边界 |
| primary / blue-soft / blue-pattern | 实际值、最终保留值、开关、焦点／区间填充／历史纹理 |
| negative / negative-ink / negative-soft | 损失图形／损失文字／浅色承载面 |
| positive / positive-ink / positive-soft | 改善图形／改善文字／浅色承载面 |
| warning / warning-ink / warning-soft | 风险图形／风险文字／浅色承载面 |

品牌橙色只用于小标识或通知提示，不扩散成所有 CTA 的颜色。主行动通常是深炭色按钮，电蓝色用于数据和开关。不要为不同业务实体随意新增一整套颜色。

## 字体与数字

采用中性无衬线字体，不依赖特定字体家族。优先使用已有系统字体；Web 默认系统 UI 栈，中文回退 PingFang SC / Microsoft YaHei，只有项目已有 Inter 等资源时再复用，勿引入外部字体下载依赖。

| 角色 | 建议字号 / 行高 | 字重 |
| --- | --- | --- |
| 页面标题 | 36 / 44 | 400–500 |
| 详情长标题 | 34 / 42 | 400–500 |
| 主 KPI | 56 / 60 | 400 |
| 洞察卡大数字 | 48 / 52 | 400 |
| 指标带数字 | 34 / 40 | 400–500 |
| 卡片标题 | 17 / 24 | 500–600 |
| 正文、表格 | 13 / 19 | 400 |
| 辅助说明 | 12 / 18 | 400 |
| 轴标签、图例 | 11 / 16 | 400 |

大标题和 KPI 可使用轻微负字距（约 -0.03em）；中文正文保持正常字距。金额、百分比、日期、表格数值开启 tabular numerals。大数字附近保留单位、时间窗口和比较基准，不能只显示无上下文的数字。字号随用户系统缩放时允许卡片增高，禁止以裁切保持固定高度。

## 几何与空间

- 间距刻度：4、8、12、16、20、24、32、40、48。
- 桌面侧栏建议 200px；内容与侧栏间距 16px；内容区内边距 24px；卡片间距 16px；卡片内边距 20px。
- 表面圆角 20px，洞察卡同级；输入框和按钮 10px；选中表格行 10px；chip 使用全圆角。
- 常规控件高 34px；触屏点击区域至少 44px；控件可保留紧凑视觉但扩大透明命中区域。
- 普通卡片 1px 边框、无阴影；按钮和菜单才用微弱阴影；弹窗阴影清楚但不泛光。
- 若制作截图式展示，可用 28px 外壳圆角和外层阴影；真实全屏应用用满视口工作区，不必保留四周“设备相框”。

## 图标与装饰

沿用项目已有的线性图标库；常规 16–18px、1.5–1.75px 线宽。小圆形状态底 32px，图标与语义颜色对应。没有文字的按钮提供可访问名称。品牌图形、头像、播放图标不属于本套组件资产。

洞察背景采用多层渐变，左上深海军蓝、右上浅蓝、右下暖杏；白色文字置于深色侧，必要时加局部深色 scrim。可在右下使用低透明度弧线／矩形轮廓，但不将装饰置于正文上。不使用全页玻璃拟态、紫色霓虹或强光晕。
